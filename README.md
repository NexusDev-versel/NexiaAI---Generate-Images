# NexiaAI---Generate-Images
Блокноты для Google Colab с нейросетями для генерации изображений бесплатно.

Данный репозиторий будет регулярно обновляться с добавлением новых блокнотов с разными нейросетями для генерации изображений.
Данные блокноты можно безприпятственно изменять под свои нужды.
Имеющиеся блокноты:
1) [Nexia] GenImage 1.0.ipynb
   * На борту настроенны 2 нейросети для генерации в реалистичном и аниме стиле. Названия маделей: 1)Anime: WAI-illustrious-SDXL v17. 2)Realistic: RealVisXL V5.0 (SDXL).
   * Особенности блокнота: Всё устанавливается и сохраняется на ваш Google Drive (Гугл диск), а именно модели, изображения и необходимые компоненты.
